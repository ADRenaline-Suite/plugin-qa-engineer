Una corrección no tiene una prueba que la hubiera cazado, o un deseo de rendimiento se escribe como un caso funcional.

## Pasos

1. Funcional comprueba el resultado del caso de uso. No funcional comprueba una medida que la persona dio (tiempo, tasa). Si no dio un número, la medida es un hueco.
2. Estructural comprueba un camino dentro del código que la persona señaló. Confirmación comprueba que una corrección nombrada se sostiene. Regresión comprueba que un comportamiento anterior nombrado sigue sosteniéndose.
3. No marques una prueba como los cinco tipos.

## Reglas

1. Una medida no funcional sin número sigue siendo un hueco.
